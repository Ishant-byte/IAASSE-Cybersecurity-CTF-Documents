# Scope and Responsible Use

This portfolio documents learning exercises conducted in intentionally vulnerable training rooms on TryHackMe. All testing should remain within the platform's authorized scope and comply with the platform's terms.

- Do not run these techniques against systems without explicit written authorization.
- Do not publish live credentials, private tokens, VPN configuration files, personal data, or sensitive platform artifacts.
- Redact target IP addresses when they are tied to a temporary lab session, and remove personal information from screenshots.
- Keep exploit details proportionate to the educational purpose and include defensive lessons where possible.
- Treat all results as lab-specific; do not imply that a real-world organization was tested.
