# Cybersecurity CTF Portfolio | IAASSE Internship

A structured portfolio of ten TryHackMe Capture the Flag (CTF) learning exercises across network security, web application security, cryptography, digital forensics, and reverse engineering. The write-ups document objectives, methodology, tools, observations, lessons learned, and defensive takeaways in a format inspired by professional Vulnerability Assessment and Penetration Testing (VAPT) reporting.

> **Portfolio status:** This repository is organized on the assumption that all ten listed rooms have been completed. Before publishing, verify the two write-ups for **Memory Forensics** and **Reversing ELF** against your actual notes, screenshots, commands, and results. Do not present example or expected outcomes as evidence you personally observed.

## How to use this repository

1. Start with the challenge index above.
2. Read each write-up for the objective, methodology, findings, and lessons learned.
3. Review screenshots only where they add evidence; redact personal information, tokens, passwords, and unrelated data.
4. For reproducibility, record tool versions, target-room context, and the exact commands you personally ran. Keep platform flags and passwords out of public files unless the platform explicitly permits publication.

## Evidence and accuracy

This repository is a learning portfolio based on authorized, intentionally vulnerable TryHackMe lab environments. Findings are limited to the stated lab context and should not be interpreted as assessments of real production systems. The two reverse-engineering/forensics write-ups that were placeholders in the source document are presented as workflow summaries; update them with your actual observations and evidence before representing them as verified results.
