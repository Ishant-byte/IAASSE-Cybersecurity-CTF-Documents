# IAASSE Cybersecurity CTF Portfolio 

A structured portfolio of ten TryHackMe Capture the Flag (CTF) learning exercises across network security, web application security, cryptography, digital forensics, and reverse engineering. The write-ups document objectives, methodology, tools, observations, lessons learned, and defensive takeaways in a format inspired by professional Vulnerability Assessment and Penetration Testing (VAPT) reporting.

## Contents

- [`Final report/`](Finalreport/): original Week 2 Word document and polished Markdown report.
- [`writeups/`](writeups/): individual challenge write-ups grouped by domain.
- [`ETHICS.md`](ETHICS.md): scope and responsible-use statement.

## How to use this repository

1. Start with the challenge index above.
2. Read each write-up for the objective, methodology, findings, and lessons learned.
3. For reproducibility, record tool versions, target-room context, and the exact commands you personally ran. Keep platform flags and passwords out of public files unless the platform explicitly permits publication.

## Evidence and accuracy

This repository is a learning portfolio based on authorized, intentionally vulnerable TryHackMe lab environments. Findings are limited to the stated lab context and should not be interpreted as assessments of real production systems.
